## python-1/day17 — 客户管理系统（CMS）

跟着课程视频练习实现的一个命令行客户管理系统：数据用两个字典存在内存里（按 id 索引、按姓名嵌套索引），支持添加、删除、修改、查询、显示全部客户。

| 文件 | 说明 |
| --- | --- |
| `CMS.py` | 主程序：菜单循环 + 增删改查逻辑，入口在 `if __name__ == "__main__"` |
| `customer.py` | `Customer` 实体类，以及 id / 姓名 / 年龄 / 手机号 / 邮箱 的静态校验方法 |

### 运行

`CMS.py` 中使用 `from day17.customer import Customer`，所以要在 `python-1` 目录下以模块方式运行：

```
cd python-1
python -m day17.CMS
```

然后在菜单里输入 1-6 选择操作（6 为退出）。

### 校验规则

- id：纯数字，且不能与已有客户重复（每项最多给 3 次机会）
- 姓名：字母或数字
- 年龄：数字且 0 < 年龄 < 120
- 手机号：11 位数字
- 邮箱：正则表达式校验格式
